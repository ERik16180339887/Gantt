Progetto per la creazione di diagrammi di Gantt direttamente dal browser web, per garantire la maggior flessibilità di utilizzo senza software dedicati.
Un solo file html che include tutto il codice, veloce e facile da condividere con chiunque senza paura di perdere informazioni
Il programma gestisce i salvataggi in due modi:
1. Esporta un nuovo file html con i dati di programmazione già memorizzati nel codice interno. Apri il file e trovi tutta la programmazione fatta, ed é comunque possibile modificarla e fare nuovi salvataggi.
2. Esporta i dati in un file JSON esterno che può essere caricato e salvato indipendentemente dal file html, comodo per avere tutti gli archivi in locale contenti solo i dati di programmazione
