Progetto per la creazione di diagrammi di Gantt direttamente dal browser web, per garantire la maggior flessibilità di utilizzo senza software dedicati.
Il programma gestisce i salvataggi in due modi:
1. esporta un nuovo file html con i dati già memorizzati nel codice interno. é comunque possibile modificarli e fare nuovi salvataggi
2. esporta i dati in un file JSON esterno che può essere caricato e salvato indipendentemente dal file html
